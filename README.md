# \# 3D Print Vault

# 

# Plex for STL Files.

# 

# 3D Print Vault is a desktop application designed to organize, track, search, and visualize large collections of 3D printing models.

# 

# \## Core Features

# 

# \- Artist Tracking

# \- Collection Management

# \- Thumbnail Generation

# \- Interactive 3D Viewer

# \- Print Tracking

# \- Duplicate Detection

# \- Advanced Search

# 

# \## Technology

# 

# \- C# .NET 9

# \- Avalonia UI

# \- SQLite

# \- Helix Toolkit
